# Homebrew tap for Kanjo

[Kanjo](https://github.com/mammut001/kanjo) shows how much AI coding agents cost per git repo.

```sh
brew install --cask mammut001/kanjo/kanjo
```

Upgrade with `brew upgrade --cask kanjo`. Uninstall with `brew uninstall --cask kanjo`
(add `--zap` to also remove settings and caches; the usage ledger in `~/.local/share/kanjo` is kept).

## 中文

```sh
brew install --cask mammut001/kanjo/kanjo
```

升级：`brew upgrade --cask kanjo`。卸载：`brew uninstall --cask kanjo`（加 `--zap` 会同时删除设置和缓存，`~/.local/share/kanjo` 里的用量账本会保留）。
